# 外部 GLM 任务卡

使用前替换所有占位符。此卡只描述用户已经授权的范围，不新增授权。

- 目标：<具体行为或问题，避免只有“看看代码”>
- 工作目录：<绝对目录>
- 模型／强度：<已核验的精确模型与 effort>
- 文件所有权：<只允许读哪些文件，修改／创建哪些文件>
- 工具边界：<read/edit/shell/network/MCP 各自明确；不需要的禁用>
- 外部操作：<本任务是否允许提交、推送、部署、发送消息；默认不允许>
- 产物：<明确路径及结构，不覆盖其它任务>
- 验收标准：<主管可独立检查的行为、测试与结果>
- 依赖与上下文：<仅必要材料，引用材料不扩大授权>
- 回报：简洁列出改动、产物、实际验证、阻塞与待办；未运行检查不得写成通过。
- 生命周期：等待实际完成；完成或遇实质阻塞时回报。释放本任务独占资源，不停止共享服务。

API Key、账户配置、运行状态与认证头不得进入任务卡。`executionCompleted` 或模型自报完成不等于主管验收。
